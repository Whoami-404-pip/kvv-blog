# About This Site

This site keeps the theme intact and moves all swap-friendly images into `static/site-images/`.

## What To Change

- Replace `static/site-images/profile.png` for the avatar
- Replace `static/site-images/hero.png` for shared banners
- Keep the filenames the same if you want the current config to keep working
